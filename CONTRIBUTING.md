# Contributing

Aitäh, et soovid Kalkulaatorisse panustada! ❤️

## Kuidas panustada?

1. Ava enne suuremat muudatust issue ja kirjelda oma ideed.
2. Forki repository ning tee muudatuste jaoks eraldi branch.
3. Tee oma muudatused ja testi need läbi.
4. Käivita testid käsuga:

```bash
python -m unittest discover -s tests -v
```

5. Ava pull request ja kirjelda, mida muutsid.

Bugide jaoks kasuta Bug report vormi ning uute ideede jaoks Feature request vormi.
